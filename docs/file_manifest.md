## 2. Core Package (`src/customer_support/`)

The application logic is structured under the `customer_support` namespace:

### 2.1 Agent Layer (`src/customer_support/agent/`)
* **`__init__.py`**: Exports `SupportAgentWorkflow`, `SupportDecisionPolicy`, and `build_support_agent`.
* **`graph.py`**: Compiled LangGraph `StateGraph` executing a 4-node pipeline:
  1. `classify`: Dual-backbone intent prediction and margin confidence calculation.
  2. `retrieve`: Semantic FAISS similarity search across verified historical brand resolutions.
  3. `draft`: Grounded reply synthesis adhering to American Airlines `#AATeam` brand voice, handling special cases (sarcasm, in-cabin lost items, loyalty status).
  4. `policy`: Multi-factor safety gating deciding `AUTO_HANDLE` vs. `ESCALATE`.
* **`policy.py`**: Implements `SupportDecisionPolicy`, evaluating incoming interactions against corporate safety rules (medical emergencies, FAA/DOT legal claims, profanity, baggage claims, flight cancellations, staff conduct grievances, and sarcasm).
* **`loader.py`**: Model resolution factory that loads the production classifier (calibrated dual-backbone ensemble or GPU SetFit model).

### 2.2 Classification Layer (`src/customer_support/classification/`)
* **`__init__.py`**: Exports baseline classifier abstractions.
* **`baselines.py`**: Implements benchmark baselines:
  - `MajorityBaseline`: Trivial majority class floor (16.0% accuracy).
  - `NearestCentroidBaseline`: Cosine distance nearest centroid classifier on sentence embeddings (60.0% accuracy).
  - `LogisticRegressionBaseline`: Scikit-learn TF-IDF Linear model baseline (56.0% accuracy).

### 2.3 Data Layer (`src/customer_support/data/`)
* **`__init__.py`**: Exports data loading and preprocessing routines.
* **`io.py`**: Implements BFS graph traversal for reconstructing multi-turn Twitter dialogue threads, tweet text normalization, regex cleaning, and deterministic split indexing.

### 2.4 Evaluation Layer (`src/customer_support/evaluation/`)
* **`__init__.py`**: Exports evaluation metrics and judge harnesses.
* **`llm_judge.py`**: Implements `ReplyQualityJudge`, scoring generated replies across a 4-dimension rubric (Grounding, Relevance, Tone, Actionability) on a 1–5 scale.
* **`ragas_eval.py`**: Implements `GroundedReplyEvaluator`, computing Ragas Faithfulness, Answer Relevancy, and Semantic Agreement against retrieved historical resolutions.
* **`metrics.py`**: Computes classification accuracy, per-class precision/recall, Macro-F1, and generates confusion matrices.

### 2.5 Labeling Layer (`src/customer_support/labeling/`)
* **`__init__.py`**: Exports labeling validation utilities.
* **`validation.py`**: Enforces strict schema constraints, candidate immutability, and cross-field integrity rules for human-annotated golden set rows.

### 2.6 Retrieval Layer (`src/customer_support/retrieval/`)
* **`__init__.py`**: Exports retrieval store components.
* **`historical_store.py`**: Implements `HistoricalResolutionStore`, wrapping a FAISS vector index of verified `@AmericanAir` resolutions with caching for sub-second retrieval.

### 2.7 Pipeline Layer (`src/customer_support/pipeline/`)
* **`__init__.py`**: Exports pipeline components.
* **`run_pilot.py`**: Driver script for executing unsupervised pilot clustering and taxonomy exploration.

## 5. Data & Model Artifacts (`data/` & `models/`)

* **`data/processed/golden_set.csv`**: The authoritative 250-row, 100% human-verified golden evaluation benchmark (10 balanced classes @ 25 rows each).
* **`data/processed/conversations.jsonl`**: 12,443 reconstructed multi-turn conversation threads.
* **`data/processed/retrieval_cache/`**: Precomputed embeddings for sub-second FAISS vector index loading.
* **`data/faiss_customer_message/`**: Vector index over customer message representations.
* **`data/faiss_full_conversation/`**: Metadata mapping for multi-turn dialogue retrieval.
* **`models/setfit_minilm_gpu/`**: Fine-tuned SetFit checkpoint (`sentence-transformers/all-MiniLM-L6-v2`) trained with contrastive cosine similarity on GPU.
* **`models/setfit_bge_small_gpu/`**: Domain-adapted SetFit checkpoint based on `BAAI/bge-small-en-v1.5`.

## 6. Scripts & Notebooks (`scripts/` & `notebooks/`)

* **`scripts/chat_tui.py`**: Implementation of the Rich Terminal IDE user interface, providing real-time chat, telemetry panels, preset benchmarks, and vectorstore candidate inspection.
* **`scripts/run_eval_harness.py`**: Standalone command-line runner for the evaluation harness.
* **`scripts/golden_set_report.py`**: Verification script reporting class balance, completion, and integrity for `golden_set.csv`.
* **`scripts/discover_fine_grained_intents.py`**: Clustering script supporting local Ollama or cloud LLMs for unsupervised intent exploration.
* **`notebooks/001_data_extraction.ipynb`**: Extraction of American Airlines tweets from raw `twcs.csv`.
* **`notebooks/002_EDA.ipynb`**: Exploratory data analysis of tweet length, reply latency, and volume.
* **`notebooks/003_conversations.ipynb`**: Development of the graph BFS thread reconstruction algorithm.
* **`notebooks/004_intent_discovery.ipynb`**: UMAP and HDBSCAN unsupervised clustering experiments.
* **`notebooks/005_golden_set.ipynb`**: 3-tier stratified sampling and golden set construction methodology.
