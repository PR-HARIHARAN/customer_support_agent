# Reports Index

Everything under `reports/` is **evidence**: each artifact is regenerated by explicit code paths (notebooks or `src/customer_support/`). Terminology is used consistently below.

- **proxy gold** = labels produced by two LLMs + an adjudicator — *not* human review.
- **human gold** = rows reviewed by a human via `label_app.py` (`data/processed/golden_set.csv`).
- **baseline** = statistical/lightweight model; **experimental / candidate / superseded** = iteration labels; **validation** = eval write-ups.
